# 便利ツール

小さいAndroidスマホでも使いやすいことを重視した、シンプルな多機能ツールアプリです。

## 主な機能

### ライト
- フラッシュライト ON / OFF
- ライト光量「弱・中・強」
  - Android 13(API 33)以降かつ対応端末では実際のトーチ強度を変更
  - 非対応端末は通常点灯へ自動フォールバック
  - CameraManagerの実状態とUI表示を同期
- 画面ライト（白・暖色・赤、明るさ調整）
- 点滅ライト
  - アプリ表示中のみ動作
  - バックグラウンド移行時は停止
  - 緊急SOS機能としては扱わない

### 測定
- コンパス（磁北基準、センサー精度表示）
  - 回転ベクトル優先
  - 非搭載端末では加速度＋磁気センサーへフォールバック
- 水平器・傾斜角
  - 左右角度 / 前後角度 / 合成傾斜角を表示
  - 端末を裏返した時の180度誤表示を抑制
- 定規
  - 端末DPI補正
  - 50〜150%の校正範囲
  - 10円硬貨（直径23.5mm）を使った画面上の校正ガイド
- 磁気メーター
  - μT表示
  - 金属探知機ではなく、磁場の変化を見る目安機能

### カメラ・読み取り
- 拡大鏡（CameraX、ズーム、対応カメラのみライト）
- QRコード / バーコード読み取り
  - ML Kitの端末内認識
  - 履歴 / コピー / 共有 / URLを開く
- 文字読み取り（OCR）
  - ML Kit日本語モデルを同梱
  - CameraX ImageCaptureで静止画を撮影して認識
  - 多重読み取りを防止
- カラーピッカー
  - カメラ中央のHEX / RGBを表示
  - カメラの露出・ホワイトバランスの影響を受けるため参考値
- カメラ系4機能は背面カメラ優先、利用できなければ前面カメラへフォールバック
- カメラ非搭載・初期化失敗時はクラッシュせず案内表示

### 作成・変換
- QRコード作成
  - 共通QR生成処理へ一本化
- Wi-Fi用QRコード作成
  - WPA/WPA2・WEP・暗号化なし向け
  - WPA3専用 / Enterpriseは読み取り端末によって非対応の場合あり
- 短縮URL作成（is.gd）
  - 「短縮する」を押した時だけ元URLを外部送信
  - 送信前に確認
  - 同じ元URLは端末内キャッシュを優先
  - 履歴 / コピー / 共有 / QR化
  - ブラウザ等の共有メニューからURLを受け取り可能
  - 連打時は最新リクエストだけを画面へ反映
- 単位変換
- 文字ツール
- 乱数 / サイコロ / YES-NO / くじ引き

### その他
- ストップウォッチ
- OS連携タイマー
  - 高精度権限がある場合は正確なAlarmManagerを使用
  - 同時に通常アラームもバックアップとして登録
  - 高精度権限がない場合も、確認後に通常精度で開始可能
  - 通常精度は省電力中に遅れる場合あり
  - 経過時間基準でカウントし、実行中の時計変更によるズレを抑制
  - 端末再起動・アプリ更新後に残り時間を復元
  - 古い予約の二重通知をトークンで無効化
  - 通知設定から戻った時は、許可済みなら保留中の開始操作を継続
- カウンター（Long値のオーバーフロー防止）
- バッテリー・端末情報
- お気に入り
- 権限・端末確認
- アプリアイコン長押しショートカット
  - ライトを直接ON
  - QR / バーコード読み取り

## 権限

### 初回起動時に確認する実行時権限
- `CAMERA`
  - ライト
  - QR / バーコード
  - 拡大鏡
  - OCR
  - カラーピッカー
- `POST_NOTIFICATIONS`（Android 13以降）
  - タイマー終了通知

初回セットアップを飛ばさないよう、アプリアイコン長押しショートカットと「共有→短縮URL」の入口もMainActivity経由に統一しています。

### 初回に案内する特別アクセス
- `SCHEDULE_EXACT_ALARM` / 「アラームとリマインダー」（Android 12以降）
  - タイマーの高精度通知用
  - 未許可でも通常精度タイマーは利用可能

### Manifestに登録する通常権限
- `INTERNET` - 短縮URL作成時のみ
- `VIBRATE` - タイマー終了
- `RECEIVE_BOOT_COMPLETED` - 再起動後のタイマー復元

位置情報、連絡先、電話、SMS、ストレージ全体、Bluetooth、Nearby Wi-Fi、バッテリー最適化除外、マイク権限は現在の機能では不要なため要求しません。

## 小画面スマホ向けUI

- トップ画面は2列グリッド
- 操作ボタンは48dpを基準
- 文字は主に14〜15sp
- 外周余白は10〜12dp中心
- 長いトップラベルは「水平器」「権限確認」へ短縮
- カメラ画面はプレビュー領域を優先
- QR読み取り結果は最大4行に制限し、長文でプレビューを押し潰さない
- 入力画面（QR作成・単位変換を含む）はキーボード表示時もスクロール可能
- Android 16 / targetSdk 36のedge-to-edgeに対応し、システムバー・ノッチ・ソフトキーボードの安全領域を反映

## プライバシー

- QR / OCR / QR生成 / Wi-Fi QR / 色取得は端末内処理
- ネット通信を使うのは短縮URL作成のみ
- 短縮URLはユーザー操作と確認後にだけis.gdへ送信
- HTTP平文通信は禁止 (`usesCleartextTraffic=false`)
- アプリバックアップは無効 (`allowBackup=false`)

## ビルド

Android Studioでこのフォルダを開き、Gradle Sync後に `app` をビルドしてください。

GitHubへ置く場合は `.github/workflows/android.yml` を同梱しており、`main` または `master` へpushするとAPI 36環境でDebug APKを作成します。

このZIPにはGradle WrapperのJARを同梱していないため、ローカルではAndroid Studio付属GradleまたはGradle 8.11.1を使用してください。
